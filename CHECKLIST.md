# Implementation Checklist & Viewer Quick Guide

## Before Delivery Checklist
- [ ] React/Vite/TypeScript project builds without errors.
- [ ] `spiderman.png` exists in the public asset path.
- [ ] `shaheer.png` or `person.png` exists in the public asset path.
- [ ] Reference image composition is respected: red grunge, white title, centered character, lower-left quote.
- [ ] Spider-Man entrance animation runs on page load.
- [ ] Cursor reveal radius is 180px on hover/move.
- [ ] Click/tap expands the reveal to 230px.
- [ ] Leaving the hero smoothly closes the reveal.
- [ ] Identity layer remains upright and centered.
- [ ] HUD appears only while the reveal is active.
- [ ] 20 ember particles animate continuously.
- [ ] Initial interaction helper fades away after first interaction.
- [ ] Touch and drag interaction works on mobile/tablet.
- [ ] Source code is available in the linked GitHub repository.

## Fast Viewer Path
1. Open the GitHub source link.
2. Run the project using the repository's available project setup.
3. Open the hero section in a desktop browser for the full cursor effect.
4. Move the cursor over Spider-Man to activate the reveal.
5. Click/tap to see the expanded 230px reveal.
6. Move away from the hero to confirm the reveal closes smoothly.
